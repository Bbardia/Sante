# Plans

This folder holds **implementation plan documents** for the Santé project.

When a non-trivial change is requested, the workflow is:

1. **Brainstorm** the intent and requirements (Superpowers `brainstorming` skill).
2. **Write a plan** here (Superpowers `writing-plans` skill) — one Markdown file per
   effort, e.g. `2026-06-02-add-stock-check.md`.
3. **Execute the plan** with review checkpoints (Superpowers `executing-plans` skill).

Naming convention: `YYYY-MM-DD-short-slug.md`.

Each plan should capture the goal, the affected parts of `Sante.py`, the step-by-step
changes, and how the result will be verified. Completed plans can be kept here as a
record of what was done and why.
